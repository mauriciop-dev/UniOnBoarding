Configuracion

        
        
        
        
URL base de Voicebox (el backend FastAPI local). Usa la primera voz clonada de tus perfiles. Contrato real: GET /profiles + POST /generate/stream → WAV. Se usa sin conexión o como fallback antes de las voces del sistema.

        

        
Modo voz (realtime)

        
        
        
        
        
En producción el Modo Voz pide a tu API un token efímero (creado con tus keys del servidor) y el usuario no configura nada. Las claves de esta sección son opcionales y se usan solo como fallback de desarrollo (chrome.storage.local, nunca a tu backend). El Gemini API key sirve para ambos proveedores; con Deepgram Agent se inyecta en el payload del "think" (BYO, sin tocar la consola de Deepgram).
